# Third-party notices

This repository contains **no Unreal Tournament content**: no Epic Games
assets, binaries, texture data, meshes, sounds or map files. The toolkit reads
an installation you provide.

## What you supply

| | source | licence |
|---|---|---|
| Unreal Tournament | your own copy | proprietary, Epic Games |
| OldUnreal 469 patch | [github.com/OldUnreal/UnrealTournamentPatches](https://github.com/OldUnreal/UnrealTournamentPatches) | see that project |
| Kenney Furniture Kit | [kenney.nl/assets/furniture-kit](https://kenney.nl/assets/furniture-kit) | CC0 (public domain) |

`SETUP.md` explains how to obtain each.

## Generated files

Some files are produced from your install rather than shipped, and are
gitignored:

- `work/textures.json`: an index of texture names and pixel dimensions read
  from your own `.utx` packages. Rebuilt automatically in ~0.2s.
- `work/*.t3d`: decompiled maps and intermediate geometry.
- `ut/OfficeProps/`: meshes converted from the CC0 Kenney kit, plus textures
  generated by `tools/pcx.py`.
- `shots/`: screenshots rendered from your own install.

## Maps you build

Maps produced by this toolkit are yours. They will normally reference textures
from Epic's stock packages by name; distributing such a map is subject to the
same conventions as any other UT99 custom map, which has been standard practice
in that community since 1999.

The office example (`maps/dm_quarterly.py`) deliberately uses generated
textures and CC0 props for most of its surfaces, so its output is close to
self-contained.
